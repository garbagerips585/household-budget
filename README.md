# Our Money

A private household budget for Tim and Scott.

**This is a look-and-feel preview with made-up numbers.** Don't enter real
information here. GitHub Pages sites are public, so real data waits until the
site moves behind a login on Cloudflare.

## What's in it

- **Home:** what's left to spend this month, with a pace line on every bar
  showing where today falls in the month; bills coming up; personal
  allowances; tax balances; savings goals.
- **Activity:** every transaction, filterable by Ours, Tim or Scott. Private
  purchases count toward totals but hide the details.
- **Bills:** what's due this week and later this month, with mark-as-paid.
- **Taxes:** the IRS and NY payment plans, the quarterly estimates, and how
  Tim's K-1 pay turns into a steady monthly paycheck.
- **Check-in:** the monthly money meeting agenda with live numbers.

Anything you add in the preview is saved only in your own browser.

## Running it

Plain HTML, CSS and JavaScript, no build step. Open `index.html`, or serve the
folder with any static server.
